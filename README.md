<h1>Hugh Fungus</h1>

<h3>Gameplay Systems Project – Godot 4.3</h3>

<h2>Overview</h2>

<p>Hugh Fungus is a two-level puzzle/combat game developed during a one-month game jam. The player travels between two worlds to gather objects and complete progression-based challenges.</p>
<p>We collaborated closely to ensure gameplay systems and visuals worked seamlessly together.</p>

<h2>Technical Highlights</h2>
<h3>State-Driven Architecture</h3>

<p>Implemented gameplay and AI using structured state machines to manage player states, enemy behavior, and combat transitions.</p>

<h3>Enemy AI</h3>

<p>Built behavior logic controlling enemy engagement, attack timing, and interaction with player states.</p>

<h3>Cross-World Data Persistence</h3>

<p>Designed a lightweight system to maintain player stats and inventory between world transitions without implementing a full serialization-based save system. This required managing persistent game state across scene changes.</p>

<h3>Combat & Inventory Systems</h3>

<p>Implemented combat resolution, stat tracking, and inventory logic tied directly into progression mechanics.</p>
